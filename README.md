# DataSentinel Research
Reliable Anomaly Detection Under Changing Data Conditions.

## Objetivo
Investigación sistemática y reproducible sobre la robustez y degradación de detectores de anomalías en series temporales bajo ruido, concept drift y desbalance severo de clases.

## Estructura
- `configs/`: Parámetros experimentales en YAML.
- `data/`: Datos crudos (UCR, NAB) y procesados.
- `src/`: Lógica del pipeline (datos, detectores, métricas, perturbaciones).
- `results/`: Tablas y figuras reproducibles.
- `app/`: Dashboard de exploración en Streamlit.
